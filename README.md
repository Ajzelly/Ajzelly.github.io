# Ajzelly GitHub Portfolio

A classy React-powered portfolio website that dynamically loads public GitHub repositories for `Ajzelly` and presents them in a polished, searchable interface.

## Features

- Live profile + repository data from the GitHub API
- Elegant glassmorphism-inspired UI with responsive layout
- Featured projects strip for top-starred repositories
- Search and sort controls (recently updated, stars, alphabetical)
- Language summary tags and portfolio stat cards

## Run locally

```bash
python3 -m http.server 4173
```

Open http://localhost:4173 and the app will load React from CDN modules.
